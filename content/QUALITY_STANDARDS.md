# Стандарты качества SEO-статей GreatIdeas.ru

## Процесс подготовки статьи

### 1. Исследование темы
- [ ] Определить основной запрос (ключевое слово)
- [ ] Собрать 5-10 LSI-ключевых слов (семантическое ядро)
- [ ] Проанализировать топ-5 статей конкурентов по этому запросу
- [ ] Выписать вопросы из "Люди также спрашивают" (Google/Яндекс)
- [ ] Собрать актуальные данные/статистику по теме

### 2. Структура статьи
- [ ] Заголовок H1: содержит ключевое слово, 50-70 символов
- [ ] Meta description: 150-160 символов, призыв к действию
- [ ] Введение: 2-3 абзаца, обозначает проблему и обещает решение
- [ ] 4-8 разделов H2, каждый с 2-4 абзацами
- [ ] H3 подразделы где уместно
- [ ] Заключение с призывом к действию

### 3. Объём и формат
- **Минимум**: 2000 слов (лонгрид)
- **Оптимум**: 3000-5000 слов для конкурентных запросов
- **Абзацы**: 2-4 предложения, не стены текста
- **Списки**: буллиты и нумерованные списки для удобства чтения
- **Таблицы**: сравнения, цены, характеристики
- **Цитаты/выделения**: ключевые мысли

### 4. Внутренние ссылки
- [ ] 3-5 ссылок на релевантные франшизы: `/franchises/SLUG/`
- [ ] 1-2 ссылки на категории: `/franchises/DIRECTION-SLUG/`
- [ ] 1 ссылка на каталог: `/franchises/`
- [ ] Ссылки на другие статьи блога если есть связанные

### 5. Изображения
- [ ] Обложка 1200x630 (OG-формат) — генерируется автоматически
- [ ] 2-4 изображения внутри статьи между разделами
- [ ] Каждое изображение с alt-текстом содержащим ключевое слово
- Типы внутренних изображений:
  - Инфографика / диаграммы (Pillow-генерация)
  - Сравнительные таблицы как изображения
  - Иллюстрации к разделам

### 6. SEO-чеклист
- [ ] Ключевое слово в H1, первом абзаце, 2-3 H2
- [ ] Ключевое слово в meta description
- [ ] LSI-слова равномерно распределены по тексту
- [ ] URL (slug) содержит ключевое слово (транслит)
- [ ] Alt-тексты у всех изображений
- [ ] Внутренняя перелинковка (3-5 ссылок)
- [ ] Нет дублей контента

### 7. Качество текста
- [ ] Не читается как AI-генерация (варьировать длину предложений)
- [ ] Конкретные цифры и факты (не "примерно", а "от 500 000 ₽")
- [ ] Экспертный тон: автор разбирается в теме
- [ ] Практическая польза: читатель уходит с ответом на свой вопрос
- [ ] Примеры из реальных франшиз на платформе

## Типы статей (ротация)

| Тип | Пример заголовка | Частота |
|-----|-------------------|---------|
| Топ по категории | «Топ-10 франшиз общепита в 2026» | Высокая |
| Обзор по городу | «Франшизы в Москве: лучшие предложения» | Средняя |
| Обзор франшизы | «Франшиза X: стоимость, условия, отзывы» | Высокая |
| Бюджетная подборка | «Франшизы до 500 000 рублей» | Средняя |
| Гайд/инструкция | «Как выбрать франшизу: пошаговый гайд» | Низкая |
| Сравнение | «Франшиза vs свой бизнес: что выгоднее» | Низкая |

## Формат JSON-файла

```json
{
  "title": "Заголовок (50-70 символов)",
  "meta_description": "SEO описание (150-160 символов)",
  "content": "<h2>...</h2><p>HTML-контент</p>",
  "tags": "ключевое1, ключевое2, ключевое3",
  "category_slug": "cafe",
  "content_type": "article",
  "entity_focus": "franchise",
  "image_url": "",
  "keywords": ["основной запрос", "LSI-1", "LSI-2"],
  "internal_links": [
    {"slug": "franchise-slug", "anchor": "Текст ссылки"}
  ],
  "section_images": [
    {"after_section": 2, "type": "infographic", "alt": "Alt текст"}
  ]
}
```
