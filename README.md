# 🚀 Great Ideas - Маркетплейс Стартапов

## 📖 О проекте


**Great Ideas** Для создания маркетплейса стартапов, которая объединяет предпринимателей с инвесторами через интерактивный планетарный интерфейс. Платформа управляет бизнес-моделями (стартапы, франшизы, агентства, специалисты), обеспечивает реальное время общение, обрабатывает инвестиции и предоставляет модерационные рабочие процессы.

### 🎯 Основные функции

#### 👨‍💼 Предприниматели
- Создание проектов (стартапы/франшизы)
- Агентства и специалисты
- Загрузка медиа (фото/видео/доки)
- Управление этапами развития
- Получение инвестиций

#### 💰 Инвесторы
- Поиск по фильтрам и категориям
- Личный портфель инвестиций
- Система рейтингов (5 звезд)
- Прямые сообщения
- Аналитика портфеля

#### 🛠 Модератор-платформа
- Vue.js дашборд управления
- Модерация контента
- Система тикетов поддержки
- Управление сделками CRM
- Аналитика платформы

## 🔧 Ключевые API эндпоинты

```bash
# Маркетплейс проектов
GET    /startups/                    # Каталог стартапов с фильтрацией
GET    /startups/{id}/              # Детальная страница стартапа  
POST   /startups/{id}/invest/       # Инвестирование в проект
POST   /startups/{id}/rate/         # Оценка проекта (1-5 звезд)

# Пользовательские панели
GET    /profile/                    # Профиль пользователя
GET    /investments/                # Портфель инвестора
GET    /my_startups/                # Мои стартапы (для стартаперов)

# Система взаимодействия
GET    /cosmochat/                  # CosmoChat мессенджер чат
GET    /deals/                      # Система управления сделками
GET    /moderator-dashboard/         # Vue.js панель модератора

# Система поддержки
GET    /support/                    # Тикеты поддержки
POST   /support/tickets/            # Создание нового тикета
GET    /support/tickets/{id}/       # Детали тикета

# JSON API для разработчиков
GET    /api/startups/               # JSON API: список стартапов
POST   /api/investments/            # JSON API: создание инвестиции
GET    /api/chat/messages/          # JSON API: сообщения чата
```

## 🌟 Особенности платформы

### 🪐 Планетарная система визуализации

**Уникальный подход** - каждый проект отображается как планета в космическом пространстве:

- **Интерактивная карта**: Навигация в 3D-космосе проектов
- **Персонализированные планеты**: Выбор визуального представления
- **Анимированные переходы**: Плавные перемещения между объектами
- **Метафорический размер**: Величина планеты = популярность проекта

### 💰 Система инвестиций

Комплексный инструментарий для финансового управления:

- **Портфель инвестора**: Все вложения в единой панели
- **Прогресс проектов**: Визуализация достижения целей  
- **История транзакций**: Полный аудит инвестиций
- **Аналитические дашборды**: Метрики доходности

### 💬 CosmoChat — Система реального времены

Продвинутый мессенджер для делового общения:

- **Прямые сообщения**: Инвестор ↔ Стартапер
- **Групповые чаты**: Командная разработка
- **Файлообмен**: Безопасная передача документов
- **Push уведомления**: Мгновенные алерты

### 🛡 Система безопасности

Многоуровневая защита платформы:

| Уровень защиты | Решение | Описание |
|----------------|---------|----------|
| **Аутентификация** | Django auth + Telegram OAuth | Двойная защита доступа |
| **Rate Limiting** | Middleware ограничение скорости | Защита от ботов |
| **CAPTCHA** | Математические задачи | Антиспам защита |
| **CSRF/Token** | Django встроенная защита | Межсайтовые атаки |
| **Файлы** | S3 pre-signed URLs | Безопасная загрузка |
| **Контент** | Автоматическая модерация | Фильтрация содержимого |

## 🔄 Рабочий процесс модерации

Система модерации контента с ролевым контролем доступа:

**Система статусов модерации предусматривает четыре состояния:**

- **Ожидает модерации** - новый контент, требующий проверки
- **Одобрено** - контент прошел модерацию и доступен пользователям
- **Отклонено** - контент не соответствует требованиям платформы
- **Черновик** - временное состояние для редактирования

**Процесс модерации включает:**
- Рассмотрение заявки модератором
- Принятие решения об одобрении или отклонении
- Добавление комментария с объяснением решения
- Автоматическое уведомление автора о результате
