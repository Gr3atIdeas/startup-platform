# Скрытые функции и страницы

Список временно скрытых элементов интерфейса. Функционал остаётся в коде и может быть восстановлен.

## Навигация (header)

| Элемент | Роль | URL | Причина скрытия |
|---|---|---|---|
| **Портфель** | investor | `/investments/` | Уход от инвестиционной модели |
| **Мои стартапы** | startuper | `/my_startups/` | Упрощение навигации |
| **FAQ** (header) | все | `/faq/` | Доступен через футер |
| **CosmoChat** | все | `/cosmochat/` | Временно отключён |

## Страницы

| Страница | URL | Статус |
|---|---|---|
| Портфель инвестиций | `/investments/` | Скрыт из навигации, URL работает |
| Мои стартапы | `/my_startups/` | Скрыт из навигации, URL работает |
| CosmoChat | `/cosmochat/` | Отключён, закрыт в robots.txt |
| Сделки (Deals) | `/deals/` | Отключён, закрыт в robots.txt |
| Franchise Landing B/C/D | `/franchise-landing-b/c/d/` | Тестовые варианты, закрыты в robots.txt |
| Franchise Cards Test | `/franchise-cards-test/` | Тестовая страница, закрыта в robots.txt |

## Как восстановить

Навигационные ссылки находятся в `accounts/templates/accounts/base.html` в блоке `{# Role-specific links #}`.
Раскомментировать/добавить нужный `<a>` тег для соответствующей роли.
